# Zero Construction 网站



## 使用方式

直接在浏览器中打开 `index.html` 即可预览，或使用本地服务器：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js (需安装 npx)
npx serve
```

然后访问 http://localhost:8000

## 文件结构

- `index.html` - 主页面
- `styles.css` - 样式
- `script.js` - 交互脚本
